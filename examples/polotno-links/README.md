# Links

A two-page flyer that already carries links: a button group that opens a web
page, a phone number, an email address linked inside rich text, and a jump to
page 2. Select an element and press **Link** to read or change its `href`.
Then download a vector PDF made with `@polotno/pdf-export`, or open the HTML
made with `@polotno/html-export`, and click the links in the output.
