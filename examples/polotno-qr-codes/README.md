# QR Codes

Demo showing how to add QR code generation functionality to Polotno editor.

The QR code keeps its content in `custom.value`. When the content is a web address, an email (`mailto:`) or a phone number (`tel:`), the element also gets an [`href`](https://polotno.com/docs/links), so the code is a link in PDF, HTML and email exports.
