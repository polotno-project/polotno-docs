# Template variables

A birthday card template with `{{name}}` and `{{sender}}` in its text and a
photo bound to the `photo` variable. Edit the variables in the Variables panel,
insert one into a text from its tooltip, then press **Preview** to fill the
template with `resolveVariables` and render the result in the browser with
`@polotno/image-export`.
